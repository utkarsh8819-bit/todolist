# To-Do List App 📝

A simple To-Do List web application to manage daily tasks.

### Features
- Add new tasks
- Manage daily tasks
- Simple and clean UI

### Technologies
- HTML
- CSS
- JavaScript

### Run Locally
1. Clone the repository.
2. Open `index.html` in your browser.
